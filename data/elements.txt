#  Une ligne :   element : forme | forme | ...
#  Le nom de la piste (donné par l'hôte, ou tapé) est découpé en mots aux
#  séparateurs, aux majuscules et aux chiffres : « SH_Kick_Hard_04 », « ClosedHat »,
#  « 808Mafia » -> « sh kick hard 04 », « closed hat », « 808 mafia ».
#    - une forme de 3 lettres ou moins (« bd », « oh », « gtr ») doit être un mot entier ;
#    - une forme plus longue peut aussi être collée à d'autres lettres (« jayykick ») ;
#    - la forme la plus longue gagne (« bass drum » est un kick, pas une basse).
#  Le nom n'est qu'un indice : l'écoute (stems/ElementClassifier.h) tranche,
#  car les sons de packs ont souvent des noms sans rapport avec ce qu'ils jouent.
#
#  Éléments : kick snare clap hihat openhat cymbal perc drumloop 808 bass keys
#  guitar brass strings pad lead pluck vocal backs fx
# =============================================================================
