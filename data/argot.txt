#  Abrasion Labs // OMNIS — Abréviations, SMS et façons de parler (version 1)
#
#  Une ligne :   forme | forme | ... => remplacement
#  Les formes sont comparées EXACTEMENT, jeton par jeton, après normalisation
#  (minuscules, accents retirés, apostrophes coupées, lettres répétées
#  réduites) : « trooo » est déjà « tro ». La forme la plus longue gagne.
#  « _ » comme remplacement : la forme est retirée (tics de langage, avis
#  sans direction comme « fire » ou « chanmé »), elle n'est ni comprise ni
#  rapportée comme mot inconnu.
#
#  Ce fichier est relu AVANT le lexique (data/lexique_fr.txt) : on y met les
#  façons d'écrire, le lexique garde les sens. Les noms d'artistes sont
#  reconnus avant cette étape (« Lil Baby » n'est pas « a little baby »).
# =============================================================================
