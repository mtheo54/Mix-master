# =============================================================================
#  Abrasion Labs // OMNIS — Lexique de la demande (base de mots, version 1)
#
#  Une ligne par concept :
#      qualite <id> : expression | expression | ... => axe valeur, axe valeur
#      defaut  <id> : expression | ...               => axe valeur, ...
#
#  « qualite » : ce que la personne VEUT quand elle le nomme (« plus brillant »,
#  « manque de crispy », « trop brillant » = moins).
#  « defaut » : ce dont elle SE PLAINT quand elle le nomme (« c'est boueux »,
#  « trop boueux » = la même plainte). Les valeurs décrivent le défaut ; la
#  correction appliquée est l'inverse.
#
#  Axes (dB sauf mention) : sub (20–80 Hz), bas (110–230), bas_medium
#  (320–640), medium (0.9–2.6 k), presence (3.6–7 k), air (10–20 k),
#  largeur (Side), sonie (LU, relatif), cible_lufs (absolu), proprete (-1 sale
#  … +1 propre), ressemblance (écart à 50 %), punch, densite, saturation
#  (-1 … +1, appliqués par les étages à venir).
#
#  Les expressions sont comparées après normalisation (minuscules, accents
#  retirés) et avec tolérance aux fautes : inutile d'écrire les variantes
#  d'orthographe, seulement les synonymes. Un fichier utilisateur peut
#  redéfinir un concept (même id) : c'est ce que fait l'apprentissage.
# =============================================================================
